![preview](art/preview/preview.png)

[中文](#中文) · [English](#english)

## 中文

卡比加入杀戮尖塔 2：吸入敌人，吞下复制能力。

### 安装

1. 在 Steam 创意工坊订阅前置模组 **RitsuLib**。
2. 订阅本模组，或者把 Release 里的 `KirbyMod` 文件夹放进游戏目录的 `mods` 文件夹。
3. 在游戏的模组列表里启用。

适用于游戏版本 0.107.1。

- 美术目前都是占位图。

## English

Kirby joins Slay the Spire 2: inhale enemies and copy their abilities.

### Install

1. Subscribe to **RitsuLib** on the Steam Workshop.
2. Subscribe to this mod, or put the `KirbyMod` folder from a Release into the game's `mods` folder.
3. Enable it in the in-game mod list.

Made for game version 0.107.1.
